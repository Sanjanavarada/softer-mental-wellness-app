
# Softer 🌷
### A little space for you.

Softer is a psychology-inspired mental wellness mobile
application designed to help users reflect on emotions,
recognize patterns of overthinking, and practice
everyday self-care.

## Technologies Used
- React Native
- Expo
- TypeScript
- JavaScript
- AsyncStorage
- Expo Camera
- Expo Audio
- Expo Video

## Features
- Personalized onboarding with customizable color themes
- Interactive daily mood check-ins
- Written, voice, and video journaling
- Overthinking self-reflection questionnaire
- Relaxing mini-games and puzzles
- Affirmation, meditation, and nature sound collections
- Personal comfort-photo widget
- Profile management and local data reset

## Running the Project

1. Clone the repository.
2. Install the dependencies:

   npm install

3. Start Expo:

   npx expo start

4. Scan the QR code using Expo Go.

## Project Status
Prototype under active development.

This application is designed for emotional self-reflection
and does not provide medical diagnoses or replace
professional mental healthcare.
